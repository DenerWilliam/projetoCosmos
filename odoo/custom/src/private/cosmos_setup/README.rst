# Cosmos Advisors Setup

Módulo de configuração inicial para a instância Odoo da Cosmos Advisors.

## Funcionalidades

- Configura dados da empresa (nome, endereço, CNPJ, etc.)
- Aplica cores da marca (azul escuro #0A1628 e rosa #E91E63)
- Configura formato brasileiro (moeda, data, idioma)
- Ajusta fuso horário para São Paulo

## Instalação

1. Acesse **Apps > Atualizar**
2. Pesquise por "Cosmos Advisors Setup"
3. Clique em **Instalar**
